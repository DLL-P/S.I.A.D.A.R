Mapa Mental do SIADAR

Lê um .pcap e agrega pacotes em flows

M3 · Anomalia

M4 · Perfil (UEBA)
planejado — baseline por usuário

planejado — falhas e vulnerabilidades

Como ler este mapa

Cor = módulo

Cada um dos cinco módulos tem uma cor fixa. Ela se repete em todo o guia — vendo a cor, você já sabe de qual parte do sistema se trata.

Traço sólido = pronto

Contorno cheio e cor forte: já existe no código. Contorno tracejado e cor apagada: ainda é plano, não implementado.

Palavra, não frase

Cada nó carrega uma única palavra‑chave (CAPTURA, TRIAGEM...). O parágrafo ao lado explica; o mapa só te ajuda a lembrar.

Uma seta = um dado real

Setas pontilhadas cinza marcam um arquivo de verdade passando de um script para outro — não é decoração, é o que roda no terminal.

1

Como o sistema pensa

Duas portas de entrada — um dataset público e uma captura ao vivo — convergem para o mesmo conjunto de 29 features. É essa peça em comum que permite treinar com dado público e aplicar em tráfego real.

2

Primeira instalação

Quatro comandos, uma vez só, dentro da pasta do projeto. Depois disso o ambiente fica pronto para todos os capítulos seguintes.

passo 1

Criar o ambiente

Um Python isolado só para o SIADAR, separado do resto da máquina.

python -m venv .venv
passo 2

Ativar o ambiente

Repita isso toda vez que abrir um terminal novo para trabalhar no projeto.

.venv\Scripts\activate
passo 3

Instalar as dependências

Scapy, pandas, scikit-learn e o resto do requirements.txt.

pip install -r requirements.txt
passo 4

Instalar o próprio SIADAR

Registra o pacote siadar para os comandos python -m siadar... funcionarem de qualquer pasta.

pip install -e .
3

Operar o sistema no dia a dia

A jornada completa, do dataset até o veredito sobre um tráfego novo. Siga a ordem — cada seta do capítulo 1 vira um comando aqui.

1 · explorar

Olhar o dataset (EDA)

Baixe o CICIDS2017 (pasta MachineLearningCVE) em data/raw/ e veja a distribuição das classes antes de treinar.

python scripts/eda.py data/raw/MachineLearningCVE
2 · treinar

Treinar o classificador

Random Forest baseline. Some --search para o modelo procurar sozinho os melhores hiperparâmetros (mais lento).

python -m siadar.classification.train \
  data/raw/MachineLearningCVE \
  --model-out models/rf_classifier.joblib
3 · capturar

Extrair flows de uma captura

Gere um .pcap com tcpdump/Wireshark, depois agregue os pacotes em flows com as mesmas 29 features do treino.

python -m siadar.capture.pcap_to_flows \
  captura.pcap -o flows.csv
4 · classificar

Aplicar o modelo

Cada flow recebe um rótulo previsto (BENIGN, DDoS, PortScan...) em predictions.csv.

python -m siadar.classification.predict \
  models/rf_classifier.joblib flows.csv \
  -o predictions.csv

5

Quando algo dá errado

As quatro falhas mais prováveis no dia a dia — todas já apareceram (ou vão aparecer) no terminal de quem opera o sistema.

"python" não é reconhecido
Causa: não há Python instalado, só o atalho da Microsoft Store.
Correção: instale o Python 3.10+ marcando "Add to PATH" na instalação.
ModuleNotFoundError: siadar
Causa: ambiente virtual não ativado, ou o pacote não foi instalado em modo editável.
Correção: rode .venv\Scripts\activate e depois pip install -e ..
Colunas esperadas ausentes
Causa: a pasta apontada não é o CICIDS2017 real, ou o CSV tem cabeçalhos diferentes do esperado.
Correção: confirme que é a pasta MachineLearningCVE e revise o dicionário _ALIASES em load_cicids.py.
FileNotFoundError: .joblib
Causa: tentou classificar antes de treinar, ou o caminho não bate.
Correção: rode train.py primeiro e confira se --model-out aponta para o mesmo arquivo usado no predict.py.
6

Expandindo o mapa

Os três ramos tracejados do mapa inicial ainda não existem em código. Quando for construí-los, repita o mesmo padrão dos módulos 1 e 2.

padrão

1. Estenda o schema

Novas features (ex.: para detecção de anomalias) entram em features/schema.py, nunca soltas nos scripts.

padrão

2. Um loader por fonte

Cada dataset novo ganha seu próprio módulo em data/, do mesmo jeito que load_cicids.py.

padrão

3. train.py + predict.py

Sempre em par, salvando o modelo com joblib — é essa ponte que faz o capítulo 1 funcionar.

Glossário visual

Uma palavra, uma ideia — para revisar rápido antes de mexer no código.

flow

Todos os pacotes de uma mesma conversa (5‑tuple: IPs, portas e protocolo) agrupados em uma linha de dados.

5‑tuple

IP origem, IP destino, porta origem, porta destino e protocolo — a "impressão digital" de um flow.

feature

Uma medida numérica calculada sobre o flow (duração, bytes, flags TCP...) que o modelo usa para decidir.

IAT

Inter‑Arrival Time: tempo entre um pacote e o próximo dentro do mesmo flow.

label

O rótulo verdadeiro (treino) ou previsto (inferência) de um flow: BENIGN, DDoS, PortScan...

scaler

Reescala todas as features para a mesma faixa de valores antes de entrar no modelo (StandardScaler).

.joblib

Arquivo onde o modelo treinado, o scaler e o encoder ficam salvos juntos, prontos para reuso.

payload_entropy

Só existe na captura ao vivo — mede o quão "aleatório" é o conteúdo dos pacotes (tráfego cifrado tende a ser mais aleatório).
